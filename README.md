## 📌 Description
This project is a Contact Details Management System developed using Python. 
It helps users store and manage contact information easily.

---

## 🎯 Objectives
- Store contact details digitally  
- Easy search and access  
- Efficient data management  

---

## 🚀 Features
✔ Add contacts  
✔ View contacts  
✔ Search contacts  
✔ Update contacts  
✔ Delete contacts  

---

## ⚙️ How It Works
The program displays a menu where users can select options to perform operations like adding, viewing, searching, updating, and deleting contacts.
